# Ary's personal website — build plan

## Content

- **Intro:** Ary; a warm, quick snapshot of who they are.
- **Things I love:** Usagi from *Chiikawa*, food, eating, and spending time with friends.
- **Now / working on:** An honest “nothing on the go right now” state, phrased playfully rather than as an empty page.
- **Opportunities:** A saved-list area for roles, programs, events, or links Ary is following and may apply for. It starts empty, with an inviting placeholder.
- **Weekly:** A newsletter area with a short description and an email-signup-style form. It can use static, local content today; no agent or external data connection is needed.
- **Local material found:** `cat-poem.txt` is available in the project folder. It can be kept as a small “tiny read” or “this week’s mood” feature if Ary wants it in the site.

## Section order

1. **Header** — Ary’s name/logo and anchor links to Now, Opportunities, and Weekly.
2. **Hero** — a clear one-line introduction: who Ary is and a cheerful visual welcome.
3. **Little loves** — Usagi/Chiikawa-inspired energy, food, and friends in illustrated cards.
4. **Now** — current status and a friendly empty-project state.
5. **Weekly** — newsletter teaser and signup interaction.
6. **Opportunities** — a tidy saved-opportunities board, initially empty but ready for future additions.
7. **Footer** — a small sign-off and optional link back to the top.

## Visual direction

Use the bright, cute, polished energy that Ary likes in W Cosmetics: a candy-pastel palette, sticker-like graphic elements, rounded cards, playful type, and high-contrast outlines. The character art should be original and Chiikawa-inspired in mood—small, expressive, cozy—not copied character art. The interface should still feel articulate and calm: generous spacing, clear headings, and a limited set of strong visual motifs (fruit, stars, bows, tiny snacks).

## What we build today

Build a responsive static personal website from the supplied local content. It will include the above sections, original CSS/SVG-style cute graphics, anchor navigation, and lightweight interactions such as a rotating cheerful note or newsletter success state. Opportunities and current projects will use thoughtful empty states. No agent integration, external CMS, or real newsletter submission is included today.
